# El legado de Sycamore Gap — exposición

Presentación web (15 min, 3 expositores) sobre el artículo:

Morelli, L., Mazzacca, G., Trybała, P., Gaspari, F., Ioli, F., Ma, Z., Remondino, F., Challis, K., Poad, A., Turner, A. y Mills, J. P. (2024). *The Legacy of Sycamore Gap: The Potential of Photogrammetric AI for Reverse Engineering Lost Heritage with Crowdsourced Data*. ISPRS Archives XLVIII-2-2024, 281–288. https://doi.org/10.5194/isprs-archives-XLVIII-2-2024-281-2024

Las figuras en `img/` vienen del artículo, publicado con licencia CC BY 4.0.

## Publicar en GitHub Pages

1. Crear un repositorio nuevo (por ejemplo `sycamore-gap`) y subir todo el contenido de esta carpeta: `index.html`, la carpeta `img/`, `guion.md` y este `README.md`.
2. En el repositorio: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, rama `main`, carpeta `/ (root)` → **Save**.
3. En uno o dos minutos queda en `https://<usuario>.github.io/sycamore-gap/`.

## Antes de exponer

- Abrir `index.html` y cambiar los nombres en el objeto `EQUIPO` (al inicio del `<script>`, cerca del final del archivo). La barra de progreso de abajo está dividida por partes con el color de cada expositor; al tocar un tramo se salta a esa parte.
- Leer `guion.md`: es el texto de cada diapositiva con sus tiempos.

## Controles

| Tecla | Acción |
|---|---|
| → / Espacio / botón Siguiente | Siguiente |
| ← | Anterior |
| N | Mostrar u ocultar el guion de la diapositiva |
| T | Iniciar o pausar el cronómetro (indica si van adelantados, a tiempo o atrasados) |
| R | Reiniciar el cronómetro |
| F | Pantalla completa |
| Botón de medio círculo | Tema claro u oscuro |

## Reparto

| Expositor | Tiempo | Diapositivas | Criterio de la rúbrica |
|---|---|---|---|
| 1 | 0:00–5:00 | Portada, agenda, contexto, problema, objetivos y datos | Comprensión del problema |
| 2 | 5:00–10:00 | Flujo, emparejamiento con IA, ajuste y punto de control, vistas del láser, videos y tronco | Comprensión del desarrollo (metodología) |
| 3 | 10:00–15:00 | Imágenes orientadas, precisión, videos, calidad en el muro, nubes, árbol virtual, web, conclusiones | Comprensión de los resultados |

Las dos diapositivas de anexo (banco de preguntas y glosario) no se exponen: sirven para que los tres puedan responder cualquier pregunta.
